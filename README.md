Плагин мобильного UI для DeepSeek Harness. Встраивается в локальный DSH, сам поднимает веб-сервер и ngrok-туннель, отдаёт React-PWA — управляй DSH с телефона из любой сети. Без домена и VPS. Авторизация, WebSocket-стриминг, установка на главный экран. Автор проекта — русскоязычный, и значительная часть сообщества плагинов DeepSeek Harness говорит по-русски.

Mobile UI plugin for DeepSeek Harness. Embeds into your local DSH, auto-starts a web server and ngrok tunnel, and serves a React PWA so you can control DSH from your phone on any network — no domain, no VPS, > installable to home screen, with auth and WebSocket streaming. The project author is Russian-speaking, and the primary audience of DeepSeek Harness plugins includes a large Russian-speaking community.
