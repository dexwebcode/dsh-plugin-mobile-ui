# dsh-plugin-mobile-ui
## Description
Mobile UI plugin for DeepSeek Harness. Embeds into your local DSH, auto-starts a web server and ngrok tunnel, and serves a React PWA so you can control DSH from your phone on any network — no domain, no VPS, installable to home screen, with auth and WebSocket streaming.

Плагин мобильного UI для DeepSeek Harness. Встраивается в локальный DSH, сам поднимает веб-сервер и ngrok-туннель, отдаёт React-PWA — управляй DSH с телефона из любой сети. Без домена и VPS. Авторизация, WebSocket-стриминг, установка на главный экран.
